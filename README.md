# Movies_API 🎬 

### Este repositorio contiene una aplicación web que consume una API de películas, desarrollada con **HTML**, **CSS** y **JavaScript**. 💻🎥🍿

## Requisitos previos

### Antes de ejecutar el proyecto, asegúrate de contar con:

- Un navegador web actualizado. 🌐🖥️

## 📥 Instalación y ejecución 📥

Sigue estos pasos para configurar y ejecutar el proyecto en tu máquina local:  

1. **Clonar el repositorio** en tu computadora:  
   ```bash
   git clone https://github.com/MiguelAndresGuerrero/Movies_API.git

## 2. Abrir el proyecto en tu editor de código (Visual Studio Code):
  #- Tener instalado la extension de Live Server en Visual Studio Code 

### Si aún no tienes instalada la extensión Live Server, agrégala desde la tienda de extensiones de VS Code.
### Abre el proyecto en VS Code.
## Haz clic derecho en index.html y selecciona "Open with Live Server".
### El navegador se abrirá automáticamente mostrando la aplicación.
